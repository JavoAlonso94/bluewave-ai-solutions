# Materiales del proyecto

Todos los archivos multimedia utilizados por IEC IA están incluidos directamente en este repositorio. La aplicación importa sus imágenes y videos desde `src/assets`; ya no depende de punteros `.asset.json` para estos materiales.

## Recursos usados por la página

| Archivo | Contenido | Uso |
| --- | --- | --- |
| `src/assets/iec-logo-light.png` | Logotipo para modo día, PNG con transparencia, 494 × 386 | Encabezado |
| `src/assets/iec-logo-dark.png` | Logotipo para modo noche, PNG con transparencia, 494 × 386 | Encabezado |
| `src/assets/team-ai.jpg` | Fotografía del equipo | Sección de equipo |
| `src/assets/ai-servers.jpg` | Infraestructura de IA | Casos y servicios |
| `src/assets/whatsapp-ai.jpg` | Automatización de WhatsApp | Casos y servicios |
| `src/assets/voice-ai.jpg` | Agentes de voz con IA | Casos y servicios |
| `src/assets/videos/batorgym-chatbot-whatsapp.mp4` | Video H.264/AAC, 1920 × 1080, 21 segundos | Demostración cinematográfica |
| `src/assets/videos/batorgym-chatbot-poster.jpg` | Portada del video, 1920 × 1080 | Vista previa del reproductor |
| `public/favicon.png` | Icono del sitio | Pestaña del navegador |

## Materiales fuente

| Archivo | Contenido |
| --- | --- |
| `reference/iec-comunicaciones-logo-original.png` | Imagen original entregada para adaptar los logotipos |

Los materiales fuente se conservan para edición y consulta; no se cargan en la página ni aumentan el peso de descarga para los visitantes.

La grabación de referencia de UX/UI no se incluye porque pesa 58.5 MB y supera el límite de 10 MB por archivo del repositorio. El archivo original entregado por el usuario no ha sido modificado.
